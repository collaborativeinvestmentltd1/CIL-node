# CIL MVP - Collaborative Investment Ltd

Production MVP for integrated property, investment, and workforce ecosystem in Nigeria.

## Project Structure

```
cil-mvp/
├── backend/          # NestJS API
├── frontend/         # Next.js web application
├── shared/           # Shared types and constants
├── docs/             # Architecture and design documentation
└── .github/          # GitHub workflows (CI/CD)
```

## Quick Start

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Tech Stack

**Frontend:** Next.js, TypeScript, Tailwind CSS, Shadcn UI, Zustand, TanStack Query
**Backend:** Node.js, NestJS, PostgreSQL
**Auth:** JWT + Refresh Tokens
**Storage:** Cloudinary
**Payments:** Paystack
**Deployment:** Render
